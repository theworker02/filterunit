# filterunit

Filter config/unit key checks for twelve-factor services.

**Site:** https://theworker02.github.io/filterunit/

## Install / run

```bash
git clone https://github.com/theworker02/filterunit.git
cd filterunit
node src/cli.js
node --test
```
